# Automated SQL Data Extraction with Python

## Overview

This project automates the process of querying a database, extracting data, and exporting it to a properly formatted Excel file using SQL and Python (pandas).
By running this script, we eliminate the need for manual query execution and Excel updates, significantly improving efficiency for recurring reports.

## Goals
Automate SQL queries – Apply necessary filters and generate required fields dynamically.
Transform data with pandas – Store the extracted data in a DataFrame.
Export to Excel – Ensure correct formatting and include the reporting month in the filename.
Improve efficiency – Remove dependency on manual Power Query refreshes and Excel interactions.
